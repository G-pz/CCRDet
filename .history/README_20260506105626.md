## 2. DATASET
We ues two drone-based RGBT tiny person detection datasets, RGBTDronePerson and VTUAV-det.

Please refer to [github page](https://nnnnerd.github.io/RGBTDronePerson/).


## 3. Installation
Please refer to <https://github.com/open-mmlab/mmdetection/tree/2.x>
### Environment
```
mmdet 2.25.1
mmcv-full 1.6.1
pytorch 1.10.0
```

## 4. Get Started
You can download our trained model from [here](https://drive.google.com/file/d/1JV_amiRn6QPb64O4fnNreSynQX1V_cqo/view?usp=drive_link) and put it in './weights'.

Use the following command to test the neural network:
```
python test.py 
```

To train a model:
```
python tools/train.py
```
